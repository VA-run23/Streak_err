# 🔥 Streak Milestones Timeline

A clean, interactive dashboard to track daily streaks across multiple platforms for career and professional development.

## 🎯 Overview

This project visualizes my commitment to continuous learning and growth by tracking daily activity streaks across various professional development platforms. The dashboard provides real-time milestone tracking and countdown timers to keep me motivated.

## ✨ Features

- **Multi-Platform Tracking**: Monitor streaks across 7+ platforms simultaneously
- **Dynamic Milestone Calculation**: Automatically calculates upcoming milestones and estimated dates
- **Live Countdown Timer**: Real-time countdown to a target date
- **Tabbed Interface**: Clean, organized view for each platform
- **Combined Timeline**: See all upcoming milestones sorted by date
- **Responsive Design**: Works seamlessly on desktop and mobile devices

## 🛠️ How It Works

The tracker uses a base date system (January 16, 2026) with initial streak values. It automatically:
- Calculates days passed since the base date
- Updates current streak counts
- Computes milestone dates
- Displays remaining days for each goal

## 📅 Milestone Levels

- Standard milestones: 400, 500, 600, 700, 750, 800, 900, 1000 days
- Platform-specific milestones for newer streaks (100, 200, 300 days)

## 🎨 Customization

To adapt this for your own use:

1. Update the `BASE_DATE` in the JavaScript section
2. Modify `INITIAL_STREAKS` with your current streak values
3. Change the `TARGET_DATE` for the countdown timer
4. Customize milestone levels in the `updateTables()` function
5. Update the greeting section with your name
